# 示例：火星殖民地法律体系研究

> 演示诸葛亮如何动态创建角色并完成复杂研究任务

---

## 用户指令

```
我想研究火星殖民地的法律体系，需要涵盖现有国际法、新法设计、伦理问题。
```

---

## 诸葛亮的思考与执行

### Step 1: 任务分析

**核心目标**：研究火星殖民地法律体系  
**涉及领域**：法律、太空政策、伦理学  
**复杂度评估**：高（跨学科、前沿领域）  
**约束条件**：无明显限制

### Step 2: 任务拆解

```json
{
  "subtasks": [
    {
      "id": "T1",
      "description": "调研现有国际太空法律框架",
      "skills_required": ["法律研究", "信息搜集", "条约谈判"],
      "priority": "P0",
      "estimated_tokens": 10000
    },
    {
      "id": "T2",
      "description": "设计火星殖民地基本法框架",
      "skills_required": ["法律起草", "逻辑推理", "制度设计"],
      "priority": "P0",
      "estimated_tokens": 15000
    },
    {
      "id": "T3",
      "description": "分析伦理问题并撰写宣言",

```

### Step 3: 角色规划

根据子任务需求，动态创建以下角色：

| 角色 | 对应子任务 | 创建理由 |
|------|----------|---------|
| **星际法学家** | T1 | 需要熟悉国际太空法律框架的专家 |
| **制度设计专家** | T2 | 需要设计新法律框架的能力 |
| **太空伦理学家** | T3 | 需要伦理学和哲学背景 |
| **法律文档师** | T4 | 需要整理和结构化输出 |

### Step 5: 任务分发

```
[诸葛亮 → 星际法学家]
任务：调研现有国际太空法律框架
交付物：现有法律框架分析报告
截止时间：30 分钟内

[诸葛亮 → 制度设计专家]
任务：设计火星殖民地基本法框架
交付物：基本法草案（含章节结构）
截止时间：45 分钟内

[诸葛亮 → 太空伦理学家]
任务：分析伦理问题并撰写宣言
交付物：伦理分析报告 + 权利宣言草案
截止时间：30 分钟内

[诸葛亮 → 法律文档师]
任务：整合所有输出为完整报告
交付物：火星殖民地法律体系研究报告
截止时间：所有前置任务完成后 15 分钟
```

### Step 7: 结果汇总

```markdown
## 任务完成报告

**任务目标**：研究火星殖民地法律体系
**参与角色**：星际法学家、制度设计专家、太空伦理学家、法律文档师
**总耗时**：1 小时 20 分钟

### 各角色输出

#### 星际法学家
- 现有国际太空法律框架分析报告
- 关键条约摘要：《外层空间条约》、《月球协定》等
- 法律真空地带识别

#### 制度设计专家
- 火星殖民地基本法草案（共 8 章 45 条）
- 权力架构设计：议会 + 法院 + 行政官
- 资源分配与产权制度

#### 太空伦理学家
- 伦理问题分析报告
- 火星居民权利宣言草案
- 代际公平、资源分配、生命伦理等建议

#### 法律文档师
- 整合版《火星殖民地法律体系研究报告》（120 页）
- 目录结构清晰，引用规范
- 包含执行摘要和关键建议

### 整合结论

1. 现有国际法对火星殖民的约束有限，需要新的法律框架
2. 建议采用"基本法 + 专门法"的双层结构
3. 伦理原则应作为法律设计的核心考量
4. 资源产权和代际公平是两大核心挑战

### 建议与后续

- 建议组建国际专家组进一步论证
- 可参考南极条约体系的经验
- 需持续关注 SpaceX 等企业的实践
```

## 经验沉淀

### 可复用角色

以下角色被标记为 `permanent`，可存入专家库：

- ✅ 制度设计专家
- ✅ 法律文档师

### 一次性角色

以下角色已销毁：

- 星际法学家（临时任务）
- 太空伦理学家（临时任务）

### 优化建议

1. 可增加"模拟反驳者"角色，主动寻找法律框架的漏洞
2. 可添加"可视化专家"，生成法律框架的图表
3. 考虑引入"历史案例专家"，参考地球上的类似案例
